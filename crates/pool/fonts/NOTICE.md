# Bundled font

`LiberationSans-Regular.ttf` — Liberation Sans, © Red Hat, licensed under the
**SIL Open Font License 1.1** (https://scripts.sil.org/OFL). Metric-compatible
with Arial. Bundled (only in `--features render` builds) so canvas `fillText`
rasterizes real, deterministic glyphs coherent with a Linux Chrome profile.
